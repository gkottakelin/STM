# BSP 独立模块索引

本页记录 2026-10-04 整理的四个模块。各模块的 README 包含接线、CubeMX 设置、头文件配置区、最小调用代码、接口说明和实物验收方法。

| 模块 | 用途 | 默认适用范围 |
| --- | --- | --- |
| [KEY](hardware/KEY/README.md) | 独立消抖、多键同时检测、可选定时连发 | STM32F103ZE HAL，普通 GPIO 按键 |
| [W25QXX](hardware/W25QXX/README.md) | JEDEC ID、读取、跨页写入校验、扇区擦除校验 | STM32F103ZE HAL，W25Q80～W25Q128、标准 SPI、3字节地址 |
| [OLED](hardware/OLED/README.md) | ASCII、数字、像素、区域填充及显存刷新 | STM32F103ZE HAL，SSD1306 128×64，8080 并口或4线软件 SPI |
| [ADC_DMA](hardware/ADC_DMA/README.md) | 多通道分批 DMA 采集、逐通道平均和电压换算 | STM32F103ZE HAL，规则组扫描、Normal DMA，默认6通道×16组 |

## 接入约定

每个模块可以单独复制，默认由 `.c`、`.h`、`README.md` 组成；OLED 额外包含必要的 `oledfont.h`。用户只在头文件配置区修改引脚、句柄和必要参数，不需要原例程的 SYSTEM、串口、LCD 或其他 BSP。

目标工程仍需提供 `main.h`、HAL/CMSIS、启动文件和链接脚本。模块只管理职责内的 GPIO 或协议：SPI、ADC、DMA、NVIC 和通道顺序由 CubeMX 按 README 生成。ADC 回调由应用统一转发，模块不抢占全局 HAL 回调定义。

各模块默认引脚按独立示例配置，**不是四个模块同时接入的统一板级配置**。例如 KEY 的 WKUP 与 ADC Rank1 默认都用 PA0，组合时必须禁用/迁移其中一项。其他外设占用也需在 CubeMX 中核对。

SPI Flash 示例会显式擦除测试扇区，使用前确认该扇区用途。ADC 示例为分批采集，批次之间有处理间隙；OLED 不支持 I²C/SH1106；这些限制详见各模块说明。

## 已完成的验证

验证日期：2026-10-04。

| 检查 | 结果及范围 |
| --- | --- |
| ARM 编译/链接 | ARM GNU GCC 12.3.1、Cortex-M3、STM32F103xE、F1 HAL V1.1.7，`-Og` 和 `-O2` 均通过；模块及 README 示例使用 `-Wall -Wextra -Werror` |
| 构建输入 | 使用本工作区实验18-3的完整 F1 HAL，以及 `00_study` 的 GNU CMSIS、启动文件、系统文件和 F103ZE 链接脚本；未将 MDK ARMASM 启动文件用于 GCC |
| 示例代码 | 从四份 README 直接提取 C 示例，连同独立验证入口和实际 HAL 初始化代码一起链接 |
| OLED 两种接口 | 默认8080、软件 SPI 分支均通过 ARM 编译/链接和主机 GPIO 总线模拟测试 |
| KEY 主机测试 | 按键抖动、同时按下、长按单次/连发、释放和毫秒计数回绕 |
| W25QXX 主机测试 | ID识别、跨页边界、读写比较、扇区对齐/擦除、保护校验失败、参数范围、忙超时和错误后CS释放 |
| OLED 主机测试 | 显存到总线传输、越界裁剪、无效字符/尺寸、三种字体 |
| ADC 主机测试 | 配置检查、交错数据平均、其他ADC回调隔离、数据就绪条件、错误/超时与停止失败恢复 |
| 独立性检查 | `.c` 无写死的板级 GPIO/总线句柄，无原 SYSTEM 依赖，不重复初始化 CubeMX 管理的总线 |

以上属于编译、链接和软件模拟验证，**尚未对这四个整理后的版本进行实物验证，也未下载到开发板**。引脚电气、屏幕模式、Flash 具体型号、采集精度和时序需要按各 README 上板确认。

验证脚本及主机测试保存在工作区 `.codex-tmp/bsp-four-validation/`，不是模块运行依赖。该目录的 ELF 仅为构建验证产物，不作为组合硬件示例固件交付。
